# Mitwirken am AllforOne Addon

Vielen Dank für dein Interesse, an diesem Projekt mitzuwirken! Hier ist eine kurze Anleitung, wie du beitragen kannst.

## Voraussetzungen

- [Git](https://git-scm.com/) installiert
- Ein [GitHub](https://github.com/) Account

## Repository klonen

```bash
git clone https://github.com/wowfusion/wfsn-allforone-addon.git
cd wfsn-allforone-addon
```

## Änderungen vornehmen

1. **Branch erstellen**
   ```bash
   git checkout -b feature/meine-neue-funktion
   ```

2. **Änderungen durchführen**
   - Bearbeite die gewünschten Dateien
   - Teste deine Änderungen im Spiel

3. **Änderungen stagen**
   ```bash
   git add .
   ```

4. **Commit erstellen**
   ```bash
   git commit -m "Beschreibung der Änderung"
   ```

5. **Änderungen pushen**
   ```bash
   git push origin feature/meine-neue-funktion
   ```

6. **Pull Request erstellen**
   - Gehe zu GitHub und erstelle einen Pull Request von deinem Branch

## Commit-Nachricht Richtlinien

- Schreibe klare, aussagekräftige Commit-Nachrichten
- Verwende Präsens ("Add feature" nicht "Added feature")
- Erste Zeile maximal 50 Zeichen

## Code-Richtlinien

- Folge dem bestehenden Code-Stil
- Teste alle Änderungen im Spiel bevor du einen PR erstellst
- Aktualisiere die `CHANGELOG.md` bei wichtigen Änderungen
- Erhöhe die Versionsnummer in `AllforOne.toc` bei neuen Releases

## Fragen?

Bei Fragen wende dich an uns über [wowfusion.de](https://wowfusion.de).
